# Workpal

A modern, dark-mode-first productivity web app built with React, TypeScript, and Tailwind CSS.

## Tech Stack

- **Framework:** React 18 + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS with a custom design token system
- **Routing:** React Router v6
- **Animation:** Framer Motion
- **Icons:** Lucide React
